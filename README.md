# Задание 1

Работа с базой данных «Аудиотека» (вариант 16): чтение, просмотр, удаление, добавление и сохранение данных. Весь функционал реализован в виде методов вспомогательных классов `AudioLibraryService`, `ExcelRepository` и `Checked` с помощью LINQ-запросов.

## Задача 1

### Текст задачи

Реализовать чтение базы данных из файла Excel. База данных «Аудиотека» состоит из четырёх таблиц: «Артисты» (код, название), «Альбомы» (код, название, код исполнителя), «Жанры» (код, название), «Треки» (код, название, код альбома, код жанра, длительность в миллисекундах, размер в байтах, стоимость в рублях). Данные из файла `LR5-var16.xls` должны быть загружены в списки объектов соответствующих классов. Содержание классов определить самостоятельно: в классах должны присутствовать свойства, конструкторы и перегруженный метод `ToString`.

### Алгоритм решения

Описаны четыре класса предметной области:

| Класс | Таблица | Свойства |
|---|---|---|
| `Artist` | Артисты | `Id`, `Name` |
| `Album` | Альбомы | `Id`, `Name`, `ArtistId` |
| `Genre` | Жанры | `Id`, `Name` |
| `Track` | Треки | `Id`, `Name`, `AlbumId`, `GenreId`, `Duration`, `Size`, `Price` |

Каждый класс содержит приватные поля с инициализацией, свойства с проверкой значений через класс `Checked`, конструктор и перегруженный `ToString()`. Связи: `Album.ArtistId → Artist.Id`, `Track.AlbumId → Album.Id`, `Track.GenreId → Genre.Id`.

1. `ExcelRepository.Load` открывает файл через библиотеку NPOI (`WorkbookFactory`).
2. Нужный лист получается по имени, строки листа отбираются LINQ-запросом (`Enumerable.Range → Select → Where`).
3. Значения ячеек читаются с проверкой в `Checked.CellText` и `Checked.CellNumber`.
4. Для каждой строки создаётся объект класса и добавляется в список.
5. Ошибки (нет файла, нет листа, пустая или нечисловая ячейка) выбрасываются как исключение с указанием строки и столбца и перехватываются в `Main`.

## Задача 3

### Текст задачи

Реализовать удаление элементов базы данных по ключу (ID). Удаление не должно нарушать целостность базы данных: нельзя удалить запись, на которую ссылаются записи других таблиц.

### Алгоритм решения

1. Пользователь выбирает таблицу и вводит ID удаляемой записи.
2. Перед удалением проверяются связи LINQ-методом `Any`: у артиста — альбомы, у альбома и жанра — композиции.
3. Если ссылки есть, удаление отклоняется с пояснением.
4. Иначе запись удаляется методом `RemoveAll` с лямбда-выражением по ID; результат — количество удалённых записей.
5. Если ID не найден, выводится соответствующее сообщение.

## Задача 4

### Текст задачи

Реализовать добавление элементов в базу данных. Код новой записи должен генерироваться автоматически, значения полей и связанные коды (ID исполнителя, альбома, жанра) — проверяться.

5. При непрошедшей проверке выводится сообщение, запись не добавляется.

# Задание 2

Реализация четырёх LINQ-запросов: один запрос к одной таблице, один — к двум, два — к трём таблицам. Два запроса возвращают перечень, два — одно значение.

## Задача 1

### Текст задачи

Вывести перечень композиций, стоимость которых не ниже заданной пользователем, упорядоченный по убыванию стоимости. Запрос обращается к одной таблице — «Треки». Результат — перечень записей.

### Алгоритм решения

1. Пользователь вводит минимальную стоимость, значение проверяется при вводе.
2. LINQ-запрос: `from track in Tracks`, `where track.Price >= minPrice`, `orderby track.Price descending`, `select track.ToString()`.
3. Результат выводится постранично, в конце — количество найденных композиций.

## Задача 4

### Текст задачи

Найдите исполнителя в жанре Metal с наименьшим суммарным размером песен в этом жанре. В ответе укажите целую часть размера его песен в мегабайтах. Запрос обращается к трём таблицам — «Треки», «Альбомы», «Жанры». Результат — одно значение. Ответ: 68.

### Алгоритм решения

1. LINQ-запрос соединяет таблицы «Треки», «Альбомы» и «Жанры» двумя `join`.
2. Отбираются композиции заданного жанра: `where genre.Name.ToLower() == genreName.ToLower()`.
3. Группировка по исполнителю: `group track by album.ArtistId into artistGroup`.
4. Для каждой группы вычисляется суммарный размер: `let totalSize = (...).Sum()`.
5. Группы сортируются по размеру, берётся первая (`FirstOrDefault`), размер переводится в мегабайты делением на 1024 дважды — целая часть и есть ответ.
